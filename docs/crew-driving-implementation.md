# Crew driving implementation

Gate A implementation checkpoint, 21 October 2026. The [reviewed scope](crew-driving-spike.md) remains the acceptance contract. This implementation is a disposable native probe, available only with `-foodtrucks-test` in an FT test character. Production crew routes still use the existing departure/arrival timer.

## Implementation chunks

1. `Core/CrewDriving`: immutable validated path, measured truck geometry, pure steering/braking, actual front-boundary checks, and per-session/controller/generation ownership. Two-controller and physical stepping tests exercise this without Unity. [Source provenance](crew-driving-provenance.md) records the limited Driven Rides reuse.
2. `CrewProbeVehicle`, `CrewDriveProbe`, `CrewProbeHooks`: unattended native engine/input ownership, initial stationary callback, actual tank/damage synchronization, parking evaluation without the HUD, guarded takeover and synchronous interruption cleanup. No cloned truck, player attachment, save schema or money operation.
3. `CrewProbeTraffic`: connected directed native waypoints, signal checks, bounded nonalloc obstacle queries including non-Gley bodies, verified native visibility and unique junction membership. The observer is deliberately conservative; unsupported routes or exhausted observation budgets refuse/stop the probe.
4. `CrewProbeBody`, `CrewProbeShape` and `CrewProbeTrigger`: bounded physical capture and a separately selected traffic certificate. Exact NWH wheel references, full suspension geometry, actual cooked-body containment, common trigger-height coverage and a required native wheel-step guard.
5. `TestBridgeCrewDrive`: start, status, stop, native waypoint inspection and read-only body/traffic evidence. No automatic parking or teleport is part of this command.

## Developer controls

Use the existing bridge ownership lock and `expect_session` protocol. All operations additionally require an FT save/character. Start with a disposable, closed food truck with no crew, schedule, transit or pending arrival. It must already be stationary and aligned at the first route point, with the player's character outside. The game must be outdoors at normal, unpaused speed. The command never changes those conditions for you.

Send command `crew_drive_probe` with these arguments:

| Operation | Arguments | Result |
| --- | --- | --- |
| Check physical body without starting the engine | `{"op":"body_contract","id":"<native vehicle ID>"}` | Independent physical geometry and native ground support; does not grant traffic certification |
| Inspect common trigger-height certification | `{"op":"trigger_coverage","id":"<native vehicle ID>"}` | Bounded pool profiles, selected/attempted band, cooked query count, per-trigger coverage and exact failure details; read-only, with native masks explicitly unchecked |
| Observe native traffic recognition | `{"op":"traffic_evidence","id":"<native vehicle ID>"}` | Nearby active Gley identities, speeds, native actions and exact body-obstacle membership; compare successive samples |
| Inspect the decisive obstacle | `{"op":"obstacle_evidence"}` | Exact collider and query captured by the active/last observer, with bounded live hierarchy/shape/body reads separately labelled; no scene scan or extra physics query |
| Inspect native collider visibility | `{"op":"visibility","id":"<native vehicle ID>"}` | Read-only collider paths, native body/parking/wheel roles, local bounds, and grouped initialized Gley masks/triggers; no probe ownership |
| Inspect nearby native road points | `{"op":"waypoints","id":"<native vehicle ID>"}` | Up to 64 nearby points with positions, directed neighbours and signal flags |
| Inspect a known chain | `{"op":"waypoints","ids":[...]}` | 1–512 exact native point records |
| Start | `{"op":"start","id":"<native vehicle ID>","waypoints":[...],"max_speed_ms":2}` | Starting state and a session/generation token; poll status for admission failure or driving |
| Status | `{"op":"status"}` | Phase/reason, native ID, generation, progress, speed, actual front clearance, tank/damage, contacts, blocker identity/query/gap, signal-transition speed/clearance and cleanup counters |
| Stop | `{"op":"stop","session":"<probe session from status>","generation":1}` | Synchronous hold and cleanup; stale session/generation is refused |

The visibility report includes exact NWH top/bottom mesh references separately from wheel ancestry, inactive and trigger colliders, reporting limits and failures. Its bounds are snapshot enclosures; mask recognition does not establish real traffic stopping.

Use actual connected native waypoint IDs, never the placeholder arrays above. The current profile permits only a straight route, 0.2–2 m/s, a 4-degree steering command and at most 5 degrees at each actual NWH wheel. It enforces a 0.2 m rear-axle corridor and 0.05 rad heading tolerance. Turns and higher speeds are refused until separately certified. The bridge prepares the native chain into samples at most 1 m apart, preserving every original marker. Continuous curvature and a 0.5 m corridor around each original segment are checked before admission. Sharp or infeasible corners are refused. Steering, projection and sweeps share that prepared path; signal membership retains the original native marker planes. A route must begin/end outside junctions. Give-way intersections are currently refused, so this probe does not yet cover every native intersection kind.

Signals and obstacles use physical braking. Gley’s stop flag combines red and amber, so the probe never infers permission to cross from a late flag change. An impossible late stop is a failed run, potentially ending in an interruption hold; it cannot count toward the contact-free campaign. The conservative swept envelope may also stop for an adjacent lane obstacle; practical clearance and signal timing remain native test gates. Save, pause, acceleration, skip, native removal and explicit stop may instead need an immediate zero-velocity/kinematic hold at the current pose. Diagnostics distinguish this interruption hold; it cannot count as a successful braking run. Fuel stays configured as the game/mods set it, and actual remaining fuel and collision damage are synchronized without repair or refill.

A stopped body can still occupy a junction. The traffic adapter retains a separately reported body record where releasing membership would hide that obstruction. This is not an offscreen journey and does not move the body. Clear it through explicit native takeover/recovery (including complete reversal behind its entry) or actual removal; repeated starts must never accumulate such records unnoticed. Normal completion must occur outside a junction with no unexplained retained state. Collider layers are never changed. Admission requires the authoritative body and every other solid, including disabled solids, to satisfy native traffic rules; only exact NWH wheel meshes covered by the body certificate receive an exception. The parking-gap proxy must stay disabled. No collider layer, mask or global collision setting is changed. Refusal before native engine acquisition only disposes probe resources; it does not hold, synchronize or stop the native vehicle.

## Body/wheel contract and straight profile (21 October 2026)

The next implementation chunk replaces the all-collider visibility rule with a shared certificate. Required body colliders remain active, enabled, solid and attached to the captured NWH rigidbody. Default collider/rigidbody layer overrides, collision-enabled state, native mask precedence, pair ignores and active trigger coverage are checked. Unknown invisible solids, changed references, unsupported shapes and conflicting rigidbodies refuse admission.

Only the exact NWH top and bottom mesh references qualify as wheels. Their full suspension travel and continuous ±5-degree yaw envelope remain in the physical dimensions and obstacle queries, including disabled bottom meshes. An analytic projected hull is an early check. Each wheel also needs a padded prism inside one actual cooked convex body, verified through native closest-point queries. Upright Gley box triggers must cover the prism's world-height band. Cooking settings, source vertices and triangle indices are guarded. This prevents a wide roof or a source mesh that differs from its cooked hull from justifying an invisible wheel near road level. The bounded source inventory permits 256 body vertices; the shipped collision mesh has 196 after export.

The required `WheelController.Step` prefix checks actual Ackermann steering and current wheel configuration before native forces run. A fault revokes commands, holds only the body still owned by that session, skips later owned wheel steps and defers cleanup until the native iteration returns. Lost save authority does not authorize native writes. Full inventory and mesh comparisons run once per observation; wheel-prefix timings and validation counters are reported separately. Harness checks cover zero steady managed allocations, replacement/session isolation and the deferred failure path.

The straight profile derives obstacle width and longitudinal padding from the same 0.2 m / 0.05 rad tracking allowances used by Core. Planar and vertical tilt allowances about the rear axle enclose permitted pitch/roll in every future sweep, including the frame change under combined tilt. Full vertical coverage is retained. Road support requires four consistent native wheel hits and a static collider whose entire upper bound stays within 1 cm of the support plane, corroborated by a ray hit. Raised or compound geometry remains a blocker. A conservative stop cannot count as physical endpoint braking.
